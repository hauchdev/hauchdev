## `05` / Principles

| Principle | What it means in practice |
|:--|:--|
| **Performance** | Profile first. Optimize the real bottleneck, not the imaginary one. |
| **Reliability** | Predictable behavior, defensive design, and repeatable builds. |
| **Developer experience** | Good defaults, useful errors, and documentation that gets to the point. |
| **Maintainability** | Clear abstractions over clever code that nobody wants to touch. |
