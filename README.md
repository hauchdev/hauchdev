## Engineering principles

- **Performance is a feature.** Measure first, then optimize the bottlenecks that matter.
- **Automation by default.** Prefer repeatable builds and checks over avoidable manual work.
- **Maintainability matters.** Favor clear structure, sensible defaults, and documentation people can follow.
- **Useful beats flashy.** Build for real workflows, not just screenshots.
